# 安卓自动识题与语音播报

Android 自动识题与语音播报项目。Android 端通过 CameraX 预览、ML Kit 本地文字识别连续确认画面变化，稳定后拍摄整幅画面；后端使用当前用户配置的视觉模型，找出所有清晰完整的题目并逐题返回答案。结果按每题“题目大意 → 答案 → 可选思路”的顺序播报。

## 多用户、邮箱与订阅

新注册须验证邮箱并由管理员审核；先在后台配置 SMTP 才能发送验证码。已有账号可直接用原密码登录，再绑定邮箱。套餐支持调用次数、题目数量、Token 三种单位，微信/支付宝商户未配置时不启用收款。配置与计费规则见 [邮箱与订阅配置](BILLING_EMAIL.md)。

支持 App / 网页注册登录，注册后须由超级管理员审核。网页后台地址为后端地址加 `/admin`，包含总览看板、用户审核/停用、角色与每日额度、密码重置、调用明细、操作日志。App 的“设置 → 账号与个人模型”可以管理个人模型 URL、模型名、API Key、密码、用量并打开管理后台。详见[账号与管理员说明](ACCOUNTS.md)。

每位用户的模型配置独立，密钥加密保存；不再使用全局模型配置或共享令牌解题。初始管理员信息自动保存至 `.tools/admin-initial-credentials.txt`，首次登录须修改密码。SQLite 数据库和加密密钥存放在 Docker 持久卷 `reader_data`，更新时保留数据卷。

## 一键部署（Windows + USB Android 手机）

准备 Docker Desktop、JDK 17，并在 Android 8.0 及以上的手机中开启开发者选项、USB 调试。电脑需能访问 Android SDK、Gradle、Maven、容器依赖源及自己选择的模型接口。首次构建会下载 Android SDK 和 Gradle，耗时较长。

1. 双击 [deploy.cmd](deploy.cmd)。脚本自动启动账号后端并生成初始管理员信息，不再要求填写全局 API Key。
2. 用 USB 连接手机，接受 USB 调试授权。
3. 脚本自动下载构建依赖、编译 APK、安装并打开 App。用初始管理员登录并设置新密码；其他用户可申请注册、等待审核。
4. 进入“设置 → 账号与个人模型”，保存自己的模型 Base URL、模型名、API Key，测试通过后即可开始识题。旧版配置会一次性迁移给初始管理员。

脚本使用 ADB 反向端口连接电脑后端。通过 `127.0.0.1` 使用时须保持 USB 连接。无线使用可启动下述 HTTPS 内网穿透，退出账号后在登录页填写临时 HTTPS 地址；也可填写可达的局域网后端地址。

单独构建 APK：`powershell -ExecutionPolicy Bypass -File .\deploy.ps1 -BuildOnly`。输出在 `android/app/build/outputs/apk/debug/app-debug.apk`。

## 云服务器部署

使用 `compose.cloud.yaml` 和 `Caddyfile.cloud`，由 Caddy 提供 HTTPS，API 端口仅在容器网络中开放。完整步骤见 [云端部署说明](CLOUD_DEPLOY.md)。手机登录页填写云端 HTTPS 地址，用账号登录后可脱离本机电脑和 USB 使用。

## 内网穿透（免服务器、免域名）

双击 `start-tunnel.cmd` 创建临时 HTTPS 地址，手机连接信息保存在 `.tools/tunnel/connection.txt`，入口使用多用户账号鉴权。电脑和 Docker 需保持运行；重启穿透后地址可能变化。双击 `stop-tunnel.cmd` 关闭外网入口。完整说明见 [内网穿透使用说明](TUNNEL.md)。

## 功能

- 设置 → 自动取景：默认开启“自动对焦题目区域”和“自动调整取景大小”。分析分辨率优先采用1280×960（由设备能力协商），按文字位置触发对焦与测光，不依赖预览界面，因此后台模式也可工作；固定焦距镜头会按设备实际能力退化处理。对焦或变焦后等待画面稳定再自动识题。
- 当前解题请求完成后才自动拍摄下一组，避免对焦、屏幕摩尔纹及文字框变化导致答案反复被替换。停止相机时清理拍照状态，过期回调不会影响新一轮拍摄；拍照超时后释放按钮并允许重试。
- 自动取景综合当前检测到的全部文字，稳定确认后小步放大，最大3倍且受硬件限制；文字贴边时优先缩小。未检测到文字时仅在1.25/1.5倍范围尝试中心搜索，随后回到广角并等待下一轮。手动缩放后自动变焦让出控制12秒，自动对焦仍有效。可在设置中分别关闭两个功能。
- 当前使用文字位置辅助取景，尚未接入YOLO，也不能判断画面外遗漏的题干或选项。复杂桌面、极小字、反光、超出镜头最近对焦距离仍可能需要调整距离或角度；数字变焦无法恢复相机原本没有采集的细节。若后续有专用题目检测模型，可用题目区域替代文字区域进行取景。

- 相机预览右下角“翻转”切换前后摄像头，记住上次选择。切换后重置缩放和稳定检测，保留暂停状态；拍摄或解题期间暂不可切换。前置镜头的识别框匹配镜像预览，发给模型的照片保持正常文字方向。
- 相机预览左下角“锁定”或“⋯ → 开启防误触锁定”屏蔽 App 内的点击和缩放，识题、预览和播报继续运行；长按解锁按钮完整 2 秒后恢复。松手、移出按钮或退到后台会取消解锁倒计时，锁定状态在返回及重启后保留。此功能只锁定 App 内界面，不屏蔽 Android 系统手势、锁屏及通知中的停止按钮。

- 设置 → 后台运行 → “后台与锁屏运行”：默认关闭，保存后保留。开启后，在 App 前台点击开始识题，再返回桌面或锁屏，独立的相机前台服务继续取帧、自动拍题、请求解答及播报；静音和蓝牙耳机限制仍然有效。常驻通知不显示题目内容，点击可返回 App，“停止后台任务”会停止相机和播报并关闭后台开关。工作期间使用有超时保护的 CPU 唤醒锁，空闲或关闭开关时释放；不会保持屏幕点亮。关闭开关后，离开界面会停止相机和播报。
- 后台模式会增加耗电，手机需允许相机和通知权限。部分品牌需在系统电池/应用启动设置里允许后台运行，可使用设置中的“打开系统后台省电设置”入口。Android 限制后台启动相机，因此重启手机、强制停止 App 或系统结束进程后，需手动打开 App 并重新开始；不承诺在系统强杀后自动恢复。其他 App 占用相机、关闭全局相机权限及厂商省电策略也可能中断相机。

- 设置 → 语音播报 → “仅连接蓝牙耳机时播报”：默认关闭，保存后生效，重启后保留。开启时所有播报（答案、单题和历史重播、状态、未识别提示）只在检测到系统蓝牙媒体输出 A2DP 或 BLE 耳机时启动；仅配对、仅通话连接、有线耳机不满足条件。断开蓝牙媒体设备或收到音频切换提示时停止并清空待播内容；重连不自动补播。无需申请附近设备权限。经典 A2DP 也可能包含蓝牙音箱，实际声音路由由 Android 管理；此开关不是强制指定输出设备，断连停止存在系统事件延迟，需在实际手机与耳机上验证。

- 设置 → 语音播报 → “播报摄像头与处理状态”：默认关闭，保存后生效并在重启后保留。开启后播报相机启动、寻找题目、拍摄、图片处理、解题与异常提示；相同状态去重、普通提示间隔至少4秒，不打断答案播报，服从一键静音。此开关不影响相机预览和识题功能。

- 点击“上传题目图片”，从系统图片选择器选择一张照片或截图，自动识别其中所有完整题目。无需开启相机或授予整个相册的访问权限。选择图片时暂停自动拍摄，取消后可点击继续恢复。原图限 50MB，自动处理方向、缩放并压缩至 8MB 内，再发送到已配置的模型服务；历史与照片保存遵循设置。
- 点击“一键静音”立即停止并禁止所有后续语音，仍可正常识题和查看答案；状态在重启后保留。点击“已静音 · 恢复声音”解除静音，再点击播报即可重听。仅控制本 App，不改变手机系统音量；展开阅读和历史页面也提供静音按钮。

- 主界面突出取景与“开始 / 暂停识题”；“拍照识题”会自动打开相机并完成拍摄。重新识别、结束识题和播报控制位于右侧“⋯”菜单，历史和设置位于顶部。
- 每题独立显示答案卡片，可展开完整题目与解析、单独播报或复制。点击“展开阅读”进入大屏阅读，阅读期间暂缓自动拍照；返回取景后恢复。
- 历史记录采用相同的卡片布局，支持单题重播；语音、识题、历史与连接参数可在设置中分组调整。
- 开始、暂停、停止连续识题；手动识别、重新识别、重播和停止播报。同一画面可识别多道完整题目，并在屏幕上同时显示全部答案。
- 双指捏合或取景画面下方的＋－按钮可实时调整相机缩放。绿色框自动标出本地识别到的文字区域，模型负责按题干和选项分组。
- 换题灵敏度、语速、音量、是否播报步骤以及历史保存可在设置中调整。
- 被裁切或看不清的题目会被略过并说明原因；后端也会拦截选项转写重复、答案字母不在选项中的可疑结果，提示复拍。网络失败可重新识别。
- 默认仅保存文字历史，题目照片默认不保存；历史页可清空普通记录，收藏题目及其已保存照片保留。收藏不会补回过去未保存的照片。
- 同一时刻只处理一个模型请求，请求期间发现新题时仅保留最新一题。

## Markdown 与题图（v1.8.0）

v1.8.1 修复答案返回后自动播报闪退：公式转语音的正则表达式显式转义右花括号，兼容 Android ICU；播报文本处理失败时保留答案并提示。新增 `MarkdownAndroidTest`，在真实 Android 上验证普通答案、分数/根式、图片过滤和公式定界符，避免仅凭桌面 JVM 测试判断兼容性。

当前结果、展开阅读和历史卡片共用原生 Markdown 渲染，支持标题、加粗、斜体、有序/无序列表、引用、代码、删除线、链接和基础表格，保留选项换行。复制保留原始 Markdown；播报自动去掉格式与图片地址。

展开“查看题目与解析”可看到原始题图，包括照片中的几何图、图表和插图；点击“查看原始题图 · 可缩放”可双指缩放、拖动、双击放大或复位。多题同框时展示整张原图，便于核对上下文，不会凭空生成图形。模型用 `![题目原图](question-source)` 在正文引用该照片。

本次结果的图片仅缓存在 App 私有目录（系统可能清理），历史照片须在设置中同时开启“保存题目与答案”和“同时保留题目照片”。旧历史中已保存的照片可直接显示；过去未保存的图片无法恢复，会在引用处提示。普通历史上限 50 题，收藏独立保留；淘汰或清空普通记录时，仅删除未被任何历史或收藏引用的照片。本次结果缓存最多保留最近两批照片，不对外提供图片下载接口。

Markdown 不执行 HTML/脚本，也不加载模型任意给出的远程图片或本地路径；图片只读取该题绑定的私有题图。支持常用 LaTeX 行内/块公式（`$…$`、`$$…$$`、`\(…\)`、`\[…\]`），不支持的公式保留源码提示。

## 配置与诊断

`.env` 只需设置后端端口等部署参数，个人模型在 App 或网页中配置。旧版 `MODEL_*` 仅用于首次迁移至初始管理员，确认导入后由初始化脚本移除；`APP_TOKEN` / `TUNNEL_TOKEN` 不再具有访问权限。APK 不再内置共享令牌。请勿提交实际密码、数据卷、初始管理员文件或备份。

后端健康检查：`http://127.0.0.1:8080/health`。查看日志：`docker compose logs -f api`。停止后端：`docker compose down`。

本机后端测试：安装 `server/requirements.txt`，运行 `python -m unittest discover -s server -p 'test_*.py' -v`。账号、权限、配额、加密存储、代理与 SSRF 约束均包含在测试中。Android 测试见 `android/app/src/androidTest`。

## 已知运行条件

自动换题检测依赖画面中的文字内容；纯图形题、极少文字题可点“手动识别”。多道题应全部清晰入镜，缩放过大可能裁切题目，缩放过小则可能无法读取文字。语音取决于手机可用的中文 TTS 引擎。

接口依据：[千问平台快速入门](https://platform.qianwenai.com/docs/developer-guides/getting-started/introduction)、[视觉理解](https://platform.qianwenai.com/docs/developer-guides/multimodal/vision)、[结构化输出](https://platform.qianwenai.com/docs/developer-guides/text-generation/structured-output)、[CameraX](https://developer.android.com/jetpack/androidx/releases/camera)、[ML Kit 文字识别](https://developers.google.com/ml-kit/vision/text-recognition/v2/android)。
